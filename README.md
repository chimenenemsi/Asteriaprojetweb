## Project Structure

- `assets/`: static files (css, js, images, templates)
- `config/`: application configuration
- `controllers/`: MVC controllers
- `models/`: business/data models
- `views/`: UI views
- `tables.txt`: database tables reference

## Local Run (Quick Start)

1. Clone the repository:
   `git clone https://github.com/chimenenemsi/Asteriaprojetweb.git`
2. Checkout the branch:
   `git checkout coaching`
3. Place project in your PHP server root (XAMPP/WAMP).
4. Import your SQL file and update DB settings in `config/`.
5. Open the project in browser.
